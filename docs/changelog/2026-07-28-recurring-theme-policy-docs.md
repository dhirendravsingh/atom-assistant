# Recurring reminders, themes, and operating policies

## Added

- Deterministic daily, weekday, weekly, weekday-specific, and monthly recurrence
  parsing with RFC 5545-style recurrence rules.
- Recurrence review, list, and editor controls.
- A persistent light/dark appearance toggle.
- Time-aware greetings for Dhiren Sir.
- Behavior, language, notification, privacy, and failure-policy documentation.
- Pull request template and mandatory per-PR changelog fragments.

## Changed

- Locale and timezone labels now use values detected from the device.
- The prototype includes a recurring reminder and an interactive recurring-flow
  shortcut.

## Validation

- Production build and server-rendered prototype test.
